# 消费贷申请流程
## 提交申请
客户阅读产品说明后填写本人资料、完成身份核验，并确认申请信息后提交。

## 查询进度
申请状态及待补材料可在 App 的申请记录中查询，客服回答不替代页面正式审批结果。
