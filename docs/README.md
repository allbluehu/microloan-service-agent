# 小额贷智能客服 Agent 文档中心

## 1. 项目定位

本项目是一个用于学习 AI Agent 工程开发的个人项目，模拟小额贷款 App 的智能客服系统。系统通过大模型理解用户问题，通过 RAG 查询经过审核的业务知识，再由确定性编排调用受控业务动作查询贷款、账单和支付数据，并在投诉、隐私泄露、冒名贷款等高风险场景转交人工。

项目重点不是“做一个聊天框”，而是展示以下工程能力：

- Java 与 Spring Boot 的业务建模能力；
- Spring AI 的模型接入、结构化输出和 RAG，以及应用层确定性业务动作编排；
- 状态机驱动的确定性 Agent 编排；
- 身份认证、资源归属校验、幂等和审计；
- Agent 可观测、可评测、可降级；
- 金融客服中的消费者权益与个人信息保护意识。

> 本项目使用模拟客户与贷款数据。简历和面试中应表述为个人项目或仿真项目，不使用未经验证的生产数据与业务收益。

## 3. 建议实现范围

MVP 必须实现：

1. 产品及流程知识问答；
2. 登录用户的申请进度、账单和还款记录查询；
3. 提前结清试算；
4. 投诉识别、工单创建和人工转接；
5. 知识来源展示、工具调用审计和全链路 Trace；
6. 越权、提示词注入和无依据回答测试；
7. 模型调用超时、熔断与人工降级（迭代四，配合故障注入测试）。

增强功能：

- Vue 客户聊天端和客服工作台；
- 对话摘要与长期会话恢复；
- PostgreSQL 全文检索与向量检索融合；
- 知识版本审批；
- Agent 评测看板；
- Resilience4j 限流（超时、熔断与降级已列入 MVP 第 7 项）。

明确不进入首版范围：

- 自动授信与风险定价；
- 自动减免、展期或债务重组；
- 自动外呼催收；
- 真实支付、真实短信和真实个人征信数据；
- 为追求形式而引入的多 Agent 协作。
